## About this mod

PlayerAnimator 9minecraft Mod powers custom movements and emotes for your Minecraft character. It acts as a shared framework so other mods can change how you pose, fight, or dance. The mod processes animation files and runs them side-by-side without breaking. Features: Plays Custom Animations: It reads animation files made in Blockbench or Blender to move your character. Layer System: Keeps things organized when multiple mods try to animate your character at the same time.
